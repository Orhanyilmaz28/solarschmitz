# Beispiel-Feeds

Testdaten für den Lieferanten-Import (Admin → Import oder `npm run import:feed`).
Alle Datensätze sind erfunden und werden beim Import als **Demo** gekennzeichnet.

- `demo-feed.csv` – Semikolon-getrennt, deutsche Dezimalkommas, gemischte Einheiten (Wh/kWh, W/kW),
  ein absichtlich fehlerhafter Datensatz ohne Preis.
- `demo-feed.xml` – XML mit verschachtelten Preisfeldern (`preise.Einkaufspreis_netto`).

Echte Lieferanten-Feeds gehören **nicht** in dieses Repository.
